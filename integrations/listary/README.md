# Listary 集成（Windows）

Zotero Bridge 桌面程序会在链接文件目录自动维护指向 `zotero://select/...` 的
`.url` 文件。文件名默认跟随 Zotero 命名模板。

## 设置步骤

1. 启动 Zotero Bridge 桌面程序并完成首次同步。
2. 打开 Zotero Bridge 设置页，确认“链接文件目录”。
3. 打开 Listary 设置 → 索引/Index，将该目录加入索引。
4. 在 Listary 中搜索作者、年份、标题或 Item Key。
5. 双击 `.url` 结果，Zotero 会打开并定位到对应条目。

不建议新旧导出目录混用。迁移时先确认新目录稳定，再从 Listary 中移除旧目录。
