Zotero Search Bridge 便携版（免安装）
=====================================

包含
----
- zsb-desktop.exe   桌面托盘程序（双击运行，状态页/设置页/自动同步）
- zsb.exe           命令行工具（搜索、同步、诊断、维护）
- zsb-config.toml   便携模式标记文件（见下文“数据位置”）
- 说明.txt          本文件

快速开始
--------
1. 启动 Zotero，并在 Zotero 中确认：
   设置 → 高级 → 允许此计算机上的其他应用程序与 Zotero 通信。
2. 双击 zsb-desktop.exe，程序最小化到系统托盘并自动开始同步；
   右键托盘图标可“显示主窗口 / 立即同步 / 暂停同步 / 退出”。
3. 命令行用法（在终端中）：
     zsb.exe doctor                 环境诊断
     zsb.exe sync                   立即同步
     zsb.exe search "燃气轮机"      本地搜索（Zotero 关闭时也可用）
     zsb.exe search "author:Smith year:2024" --format json
     zsb.exe open --library user --key N49R8KAQ
     zsb.exe status                 查看索引状态

Listary 集成
------------
托盘程序“设置”页可查看镜像目录；把它加入 Listary 索引，即可按
作者/年份/标题 搜索并双击定位。默认镜像目录：
  %LOCALAPPDATA%\ZoteroSearchBridge\mirrors\windows\
也可在设置页改到你已有的 Listary 索引目录。

数据位置（便携模式）
--------------------
本压缩包自带一个 zsb-config.toml。只要它与 exe 放在同一目录，
程序即进入“便携模式”，全部数据都保存在 exe 旁边的 data\ 目录：
  配置：<本目录>\zsb-config.toml
  索引：<本目录>\data\index.sqlite
整个文件夹可以随意移动、放 U 盘；删除该文件夹即完全卸载。
（注意：便携模式下日志仍写入用户目录 %LOCALAPPDATA%\ZoteroSearchBridge\logs\。）

如果删掉 zsb-config.toml，则退回系统默认位置：
  配置：%APPDATA%\ZoteroSearchBridge\config.toml
  索引：%LOCALAPPDATA%\ZoteroSearchBridge\data\index.sqlite

自定义路径（四种方式，优先级从高到低）
--------------------------------------
1. 命令行参数（仅 zsb.exe）：
     zsb.exe --config D:\zsb\config.toml --database D:\zsb\index.sqlite sync
2. 环境变量：
     ZSB_CONFIG=D:\zsb\config.toml
     ZSB_DATABASE=D:\zsb\index.sqlite
3. 配置文件里的 [storage] 段（支持 %VAR% 和 ~ 展开，
   也可在托盘程序“设置 → 存储”页修改，改后需重启程序）：
     [storage]
     database = "D:\\zsb\\index.sqlite"
4. 默认位置（便携模式 = exe 旁 data\；否则 = 上述系统目录）。
